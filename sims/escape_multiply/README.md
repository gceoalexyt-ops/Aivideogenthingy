# Every Escape = 3 More Balls (physics-sim channel)

`escape_multiply_short.mp4`: 13.5 s, 1080x1920, 60 fps. No voiceover.

One ball starts in a spinning neon ring with a 50° gap. Every ball that escapes spawns 3 new ones in
the middle, so the count explodes: 1 → 25 by 6 s → 466 by 11 s → 1000 at 12.0 s, when the ring
shatters. Bounces play *Ode to Joy* (Beethoven, public domain), and the escape pops climb in pitch.
This is plain 2D physics, vectorised with numpy, with nothing keyframed (seed 3; `--search` lists others).
